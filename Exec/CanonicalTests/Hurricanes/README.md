# Running Hurricane Simulations with WRF Files

This folder contains the input files (with links to WRF files) for running different hurricane simulations.

## Running a Hurricane Simulation

1. Download the required WRF files from the corresponding links below.
2. Compile ERF by running:
   ```bash
   make -j8
   ```
   in the `Exec` directory.
3. Run ERF using the corresponding `inputs` file.

## Example
